# Catch-The-Turtle

A small, educational **Python** click game created while learning the language. This repository preserves the activity history and experiments I made while practicing basic game logic and user interaction.

---

## About

**Purpose**  
This project is a simple learning exercise. It demonstrates how to build a minimal interactive game in Python where the player clicks a target that appears on the screen to score points.

**Scope**  
The code focuses on clarity and readability to help beginners follow the logic. It is intentionally small and easy to extend as you learn more.

---

## Features

- **Simple gameplay**: Click the target that appears on the screen.  
- **Scoring**: Score increases on each successful click.  
- **Readable code**: Clear variable names and comments for learning.  
- **Extensible**: Easy to add levels, sounds, or a high score table.
